# AndinaTrading

AndinaTrading is a project focused on simulating and managing trading operations. It was designed as part of a microservices architecture, where this service communicates with two additional services to provide trading functionalities.

**## Technologies Used:**

- **Backend:** Spring Boot (Java)
- **Frontend:** React + TypeScript
- **Database:** MySQL
- **Testing:** JUnit
- **Version Control:** Git & GitHub

**## Microservices Architecture:**

AndinaTrading is one of three services in the system for core trading operations and user interface.

Each service runs independently and communicates via REST APIs.

**## Repository Structure:**

AndinaTrading/
- frontend/  #React + TypeScript
- backend/   #Spring Boot + Java

**## Project Setup:**

**Backend**
1. Clone the repository: `git clone https://github.com/paulaguerrerop/AndinaTrading`
2. Navigate to the backend folder: `cd AndinaTrading/master`
3. Run with Maven: `mvn spring-boot:run`
4. Backend will be available at: `http://localhost:8080`

**Frontend**
1. Navigate to the frontend folder: `cd AndinaTrading/frontend`
2. Install dependencies: `npm install`
3. Run: `npm start`
4. Frontend will be available at: `http://localhost:3000`
